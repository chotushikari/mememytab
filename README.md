## Under the hood

No AI. No server. No background worker. No tracking.

MemeMyTab changes image sources in the tab, watches for lazy-loaded images, and scans as you scroll. Photos stay in Chrome's local storage. That is the whole trick.

Use photos you have permission to use. Be funny, not awful.

## Inspiration

Inspired by [LeReplacerExtension](https://github.com/ShreyShingala/LeReplacerExtension). This is a fresh, minimal implementation with user photo decks and local-only operation.
